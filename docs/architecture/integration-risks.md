## Остаточный риск

`RISK-006` остаётся открытым: текущий контур не опрашивает Bitrix24 для периодического сравнения с локальными `approved`-заявками. Для production нужны владелец процесса reconciliation, частота проверки, правила восстановления и аудит ручных изменений; эти параметры нельзя обоснованно назначить без эксплуатационного контекста.
