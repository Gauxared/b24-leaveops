# Требования

Канонический набор требований разделён по типам. Идентификаторы сохранены относительно предыдущей версии кейса.

- [Бизнес-требования](requirements/business-requirements.md)
- [Бизнес-правила](requirements/business-rules.md)
- [Функциональные требования](requirements/functional-requirements.md)
- [Нефункциональные требования](requirements/non-functional-requirements.md)
- [Критерии приёмки](requirements/acceptance-criteria.md)
- [Таблицы решений](requirements/decision-tables.md)

Требования описывают реализованный демонстрационный контур. Их аналитическое происхождение реконструировано по коду, тестам, DDL и обобщённой AS-IS модели; формальное согласование с бизнес-заказчиком не заявляется.
