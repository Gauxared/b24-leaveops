# UC-05 — контролировать доступность команды

| Поле | Значение |
| --- | --- |
| Цель | Получить разрешённую по роли картину отсутствий, покрытия и баланса |
| Основной актор | Сотрудник или руководитель |
| Вторичные акторы | LeaveOps |
| Триггер | Актор выбирает период или расчётную дату |
| Предусловия | Актор активен |
| Постусловия | Данные прочитаны без изменения состояния |

## Основной поток

1. Актор открывает календарь периода до 31 дня.
2. LeaveOps возвращает активных сотрудников отдела, `approved`/`submitted` периоды и покрытие.
3. Актор запрашивает свой баланс; руководитель может запросить баланс сотрудника своего отдела.
4. Руководитель открывает HR-сводную с балансами, pending-заявками и ближайшими отсутствиями.

## Ограничения и исключения

- Календарь не раскрывает причины и историю чужих заявок.
- Баланс другого сотрудника недоступен обычному сотруднику.
- HR-сводная доступна только руководителю.
- Некорректная дата или период больше 31 дня возвращает `invalid_dates`.

**Правила:** `RULE-03`, `RULE-05`–`RULE-08`.<br>
**Требования:** `FR-01`, `FR-07`, `FR-08`, `NFR-04`.
**Критерии:** `AC-AVL-001`, `AC-BAL-001`, `AC-HR-001`.
