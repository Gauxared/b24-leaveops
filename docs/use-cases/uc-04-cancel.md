# UC-04 — отменить заявку

| Поле | Значение |
| --- | --- |
| Цель | Завершить собственную заявку и убрать согласованное отсутствие из внешней проекции |
| Основной актор | Сотрудник |
| Внутренние компоненты | LeaveOps Service, outbox |
| Связанный сценарий | Доставка отмены выполняется отдельно по `UC-06` |
| Триггер | Автор выбирает отмену |
| Предусловия | Статус `draft`, `submitted` или `approved` |
| Постусловия | `cancelled`; для бывшей `approved` создан outbox `cancel` |

## Основной поток

1. LeaveOps подтверждает владельца и допустимый статус.
2. LeaveOps сохраняет `cancelled` и историю.
3. Для `approved` в той же транзакции создаётся `cancel`.
4. Заявка перестаёт влиять на баланс и покрытие.
5. Отдельный `UC-06` доставляет отмену; уже отсутствующая внешняя цель считается успехом.

## Альтернативные потоки и исключения

- Отмена `draft` или `submitted` не создаёт интеграционного события.
- Чужой актор получает `forbidden`.
- Повтор отмены получает `invalid_transition` без второй записи истории.

**Правила:** `RULE-01`, `RULE-10`.<br>
**Требования:** `FR-05`, `FR-10`, `NFR-01`, `NFR-02`.
**Критерий:** `AC-CAN-001`.
