# UC-01 — создать и отправить заявку

| Поле | Значение |
| --- | --- |
| Цель | Передать руководителю корректно оформленный период отсутствия |
| Основной актор | Сотрудник |
| Вторичные акторы | LeaveOps |
| Триггер | Сотрудник выбирает начало и конец периода |
| Предусловия | Сотрудник активен; демо-база инициализирована |
| Постусловия | Заявка `submitted`; история содержит создание и отправку |

## Основной поток

1. Сотрудник указывает даты.
2. LeaveOps проверяет формат, существование и порядок дат.
3. LeaveOps создаёт собственную заявку `draft` и запись истории.
4. Сотрудник отправляет черновик.
5. LeaveOps подтверждает владельца и переводит заявку в `submitted`.

## Альтернативные потоки

- Сотрудник оставляет заявку в `draft` и отменяет её по UC-04.
- До решения `submitted`-заявка не резервирует баланс и покрытие.

## Исключения

- Неверная дата или обратный период: `invalid_dates`, заявка не создаётся.
- Неизвестный или неактивный актор: `forbidden`.
- Чужой актор пытается отправить заявку: `forbidden`.

**Правила:** `RULE-01`, `RULE-03`, `RULE-07`.<br>
**Требования:** `FR-02`, `NFR-04`.
**Критерий:** `AC-REQ-001`.
