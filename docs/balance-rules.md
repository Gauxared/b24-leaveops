# Расчёт отпускного баланса

LeaveOps использует прозрачную демонстрационную модель, которая показывает доступный остаток на дату заявки и прогноз после согласования. Она не заменяет кадровый расчёт.

## Исходные данные

Для каждого сотрудника задаются:

- `opening_days` — начальный остаток;
- `accrual_start` — первый месяц начисления;
- `monthly_accrual_days` — число дней, начисляемых первого числа каждого месяца.

## Формула

На дату `as_of` сервис считает:

```text
начислено = число месяцев от accrual_start до as_of включительно × monthly_accrual_days
использовано = дни согласованных отсутствий, завершившихся не позже as_of
запланировано = дни согласованных отсутствий, начинающихся после as_of
доступно = opening_days + начислено − использовано − запланировано
```

При решении по заявке расчёт выполняется на дату её начала. Если после вычитания дней новой заявки баланс становится отрицательным, согласование блокируется с кодом `balance` и числовым объяснением.

Заявки в статусах `draft` и `submitted` не резервируют дни. Баланс повторно проверяется в одной транзакции с согласованием.

## Доступ

- Сотрудник читает только собственный баланс и прогноз своей заявки.
- Руководитель читает балансы сотрудников своего отдела и HR-сводную.
- Ограничения проверяются сервисом и HTTP-слоем.

## HTTP API

- `GET /api/balance?id=EMPLOYEE_ID&as_of=YYYY-MM-DD`
- `GET /api/hr-summary?as_of=YYYY-MM-DD`
- `GET /api/request?id=REQUEST_ID` возвращает текущий баланс и прогноз после согласования.

Не учитываются праздники, смены, компенсации, перенос между годами и нормы трудового законодательства.
