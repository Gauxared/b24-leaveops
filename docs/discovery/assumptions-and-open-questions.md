# Допущения, ограничения и открытые вопросы

## Подтверждено реализацией

| ID | Факт | Доказательство |
| --- | --- | --- |
| `EV-001` | Период включает начальную и конечную даты | `_days`, `_conflicts`, тест границы пересечения |
| `EV-002` | Покрытие проверяется только в будни | `_conflicts`; `working_iso_weekdays=[1..5]` в seed |
| `EV-003` | `draft` и `submitted` не резервируют баланс и покрытие | SQL-фильтр `status='approved'` и тесты |
| `EV-004` | Решение, история и outbox записываются в одной транзакции | `_connection(write=True)`, `transition`, integration tests |
| `EV-005` | Открытый перенос не меняет действующий период | `reschedule_proposals`, workflow/web tests |
| `EV-006` | Реальный адаптер ищет метку перед созданием | `Bitrix24CalendarAdapter._find` и contract tests |

## Аналитические допущения

| ID | Допущение | Основание | Проверка для production |
| --- | --- | --- | --- |
| `ASS-001` | Один сотрудник относится к одному отделу | Демо-модель `employees.department_id` | Сверить оргструктуру и совместителей |
| `ASS-002` | Один руководитель отвечает за отдел | `departments.manager_id` | Определить заместителей и матричное согласование |
| `ASS-003` | LeaveOps — источник решения, Bitrix24 — проекция | Односторонний исходящий адаптер | Согласовать владельца данных и правила reconciliation |
| `ASS-004` | Сотруднику достаточно видеть общую доступность отдела | Проекция `/api/calendar` скрывает историю и причины | Провести privacy review с HR и сотрудниками |

## Ограничения демонстрации

| ID | Ограничение | Последствие |
| --- | --- | --- |
| `CON-001` | Рабочий календарь содержит только Пн–Пт без праздников | Баланс и покрытие не пригодны для кадрового расчёта |
| `CON-002` | `X-Demo-Actor` — переключатель роли | Нет production-аутентификации и доверенной идентичности |
| `CON-003` | HTTP-сервер слушает loopback | Демо нельзя публиковать как production web service |
| `CON-004` | Worker запускается вручную | Нет фонового backoff, алертов и операционного SLA |
| `CON-005` | Полная карта шести сотрудников не проверена в Bitrix24 | Доказана модель маршрутизации, а не полный rollout |
