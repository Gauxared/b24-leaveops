# Демонстрационный сценарий

## Запуск

```powershell
python -m leaveops init
python -m leaveops.web
```

Откройте http://127.0.0.1:8765. Если база уже заполнена, повторять `init` не нужно.

## Согласование заявки

1. Выберите «Аналитик Б» и создайте заявку на 15–16 октября 2026 года.
2. Отправьте заявку руководителю.
3. Переключитесь на «Руководитель». Карточка покажет прогноз баланса и результат проверки покрытия.
4. Согласуйте заявку и отправьте ожидающее событие в Mock Bitrix24.
5. Откройте карточку повторно: бизнес-статус и статус доставки отображаются отдельно.

## Проверка конфликта

Создайте заявку «Аналитика Б» на 14–16 октября. На 14 октября доступных аналитиков останется меньше установленного минимума. Согласование будет заблокировано, а карточка покажет дату, роль, доступное и требуемое количество сотрудников.

## Перенос периода

1. В роли автора откройте согласованную заявку и предложите даты 20–21 октября.
2. До решения руководителя календарь продолжает учитывать старый период.
3. В роли руководителя сравните действующий и предложенный периоды и согласуйте перенос.
4. После синхронизации Mock Bitrix24 содержит обновлённый объект с прежним внешним ID.

## Проверка из командной строки

```powershell
python -m unittest discover -s tests -v
python -m leaveops.demo
python -m leaveops.integration_demo
```

Команды используют синтетические данные и временные базы.
